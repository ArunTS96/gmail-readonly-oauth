Personal Gmail Read-Only Integration

A private, single-user automation integration. Application name on the Google consent screen: foragent.

What this application is

This is not a product and not a public service. It is a personal automation tool built and used by one person, on their own machine, against their own Google account only. There is no sign-up, no other users, and no server that receives anyone else’s data.

What it does

It reads the owner’s own Gmail inbox to find billing statements, travel booking confirmations, and similar documents the owner already receives, so that a local assistant can remind the owner of payment due dates and keep travel paperwork organised on the owner’s own computer.

Google user data accessed

Exactly one OAuth scope is requested:

  • https://www.googleapis.com/auth/gmail.readonly — read-only access to Gmail messages and metadata.

No other Google product or scope is requested. There is no write, send, delete, or modify capability: the integration cannot send mail, cannot delete mail, and cannot change anything in the mailbox. Those operations are verified as rejected at the API level.

How the data is handled

  • Authorization tokens are stored locally and encrypted on the owner’s own machine.
  • Message content is read on demand and is never transmitted to any third party.
  • Data is not sold, shared, transferred, or used for advertising, profiling, or credit-worthiness purposes.
  • Access can be revoked by the owner at any time, at which point the tooling stops working immediately.
