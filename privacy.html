Privacy Policy

Personal Gmail Read-Only Integration (consent-screen name foragent) · last updated 3 October 2026

Who this applies to

This application is a private, single-user tool. The only person who authorises it is its owner, using the owner’s own Google account, on the owner’s own computer. No other person is a user of this application.

What Google user data is accessed

ScopePurpose
gmail.readonly Read-only access to the owner’s own Gmail messages and metadata, so the local assistant can locate statements, booking confirmations and similar documents the owner already receives, and remind the owner of payment due dates and travel paperwork.

No other scope is requested. The application cannot send, delete, modify, label, or otherwise write to the mailbox.

How data is used

  • Message data is used solely to produce reminders and document summaries for the owner.
  • Processing happens locally on the owner’s own machine.
  • Message data is not used to determine credit-worthiness, for lending, for advertising, for profiling, or for any purpose unrelated to the owner’s own convenience.

What is never done with the data

  • It is not sold.
  • It is not shared, transferred, or disclosed to any third party, including advertisers, data brokers, or analytics providers.
  • It is not used to train or improve any machine-learning model offered to third parties.
  • Humans other than the owner do not read it.

Storage, security and retention

  • OAuth credentials and tokens are stored encrypted, locally, protected by the operating system’s credential store. They are never embedded in this website or in any public repository.
  • Any cached message content stays on the owner’s own device and is plain files readable only by the owner’s user account.
  • Content is retained only as long as it is useful to the owner for the reminder purpose above, and can be deleted by the owner at any time.

Revoking access and deleting data

The owner can revoke this application’s access at any time at myaccount.google.com/permissions. Revocation takes effect immediately: the integration stops working, and locally stored tokens and cached content can be deleted from the owner’s machine by the owner.

Children

This application is not directed at children and is not offered to any third party.

Google API Services User Data Policy

This application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
